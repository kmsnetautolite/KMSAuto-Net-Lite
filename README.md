# Auto Net Lite

Offline local volume  helper with silent renewal scheduling, Office C2R-to-VL channel switching, and WinDivert loopback hooks for VBS systems.

##  Subsystems
* **Renewal Scheduler**: Background task refreshing local volume leases automatically.
* **WinDivert Hook**: Loopback routing when Virtualization-Based Security blocks standard taps.
* **Product Detector**: Scans installed OS and Office SKUs offline without outbound calls.
